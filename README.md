What is Hours?
Hours is an experimental digital currency that enables instant payments to anyone, anywhere in the world. Hours uses peer-to-peer technology to operate with no central authority: managing transactions and issuing money are carried out collectively by the network. Hours Core is the name of open source software which enables the use of this currency.
